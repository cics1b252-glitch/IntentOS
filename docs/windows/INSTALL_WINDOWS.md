# Instalar Intent OS Product Alpha 2.1.4 no Windows

1. Baixe `IntentOS-Product-Alpha-2.1.4-Setup.exe` e `CHECKSUMS.txt`.
2. Optionally compare the setup SHA-256 hash with `CHECKSUMS.txt`.
3. Double-click setup and confirm installation.
4. Choose whether to create the optional Desktop shortcut.
5. Open **Intent OS** from the Start menu and complete the Portuguese first-run setup.

Installing over the previous Alpha replaces program files while preserving `%LOCALAPPDATA%\IntentOS\Data`.
OpenAI and Google Gemini are supported. Provider keys are protected for the current Windows user.

Administrator access and Python are not required. This unsigned alpha may trigger SmartScreen.

To remove it, use **Settings → Apps → Installed apps → Intent OS Alpha → Uninstall**. The uninstaller
asks whether local data should be erased. Choose **No** to preserve it or **Yes** to erase it.
