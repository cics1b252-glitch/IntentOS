# Windows Data Directories

| Directory | Purpose | Removed by default? |
|---|---|---|
| `preferences` | Host defaults and first-run marker | No |
| `logs` | Minimal lifecycle and host-error logs | No |
| `cache/webview2` | Embedded browser profile/cache | No |
| `future-kc` | Reserved only; no Knowledge Core yet | No |
| `backups` | Reserved for future backups | No |
| `updates` | Reserved for future in-place updates | No |

Logs never include typed content, prompts, documents, credentials, keys, or provider payloads.
