# First Run Onboarding

Product Alpha 1 starts in Portuguese with five explicit steps: welcome, local-data ownership,
Provider selection, basic presentation preferences, and confirmation. Completion is written only
after the user chooses **Abrir conversa**. Closing earlier leaves onboarding incomplete.

The default path is real mode with no Provider. Demonstration mode requires an explicit choice and
remains visibly labelled. Local files live under `%LOCALAPPDATA%\IntentOS\Data`.
